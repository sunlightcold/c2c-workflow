# 单仓库项目边界

后端位于根仓库的 `projects/backend`，管理后台位于 `projects/admin-web`。两者共享同一套 Git 历史，但保留独立的 pnpm workspace、锁文件、构建命令和依赖边界。

## 后端职责

- 提供身份认证、RBAC、菜单、任务、日志、参数和对象存储等平台能力。
- 承载商家、C2C 订单、支付、Telegram、代理商和外部平台适配器。
- 作为权限、租户隔离、状态迁移和资金操作的最终裁决者。

## 前端职责

- 提供平台运营人员和代理商使用的管理界面。
- 消费后端 DTO 和权限码，不在浏览器中实现业务裁决或 Secret 解密。
- 模板中的用户 App、商品、积分、价格方案和 App 订单不属于产品范围。

## 参考代码

`templates/*` 是 Git 忽略的临时只读材料，不属于构建和发布链路。参考实现中的 MongoDB 模型、明文 Secret、MD5 密码、跨租户权限和单进程机器人架构不得进入产品代码。

跨项目变更遵循根目录 `docs/OPERATING.md` 的契约优先流程。
